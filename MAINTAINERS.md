# Maintainers

CorpusLedger is currently maintained by [@appleweiping](https://github.com/appleweiping).

Maintainers review compatibility, provenance, streaming behavior, security, documentation, and release evidence.
Contributions are accepted through pull requests; a maintainer remains accountable for every merged change.

Security reports must use [private vulnerability reporting](https://github.com/appleweiping/corpusledger/security/advisories/new).
