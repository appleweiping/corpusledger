# Support

- Use [Discussions](https://github.com/appleweiping/corpusledger/discussions) for usage questions and design ideas.
- Use [Issues](https://github.com/appleweiping/corpusledger/issues) for reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/appleweiping/corpusledger/security/advisories/new) for security concerns.

Support is best-effort. Public reports must use a minimal synthetic corpus and must not include corpus records,
credentials, personal data, private keys, or key passwords.
